Getting started

VinylBot combines Spotify control with an interactive music guessing game. Play song previews in your server and challenge your community to guess the titles — first correct answer earns points, with a leaderboard, badges and win-streak tracking.

Add to Discord View on GitHub

⚠️ Hosted instance disclaimer

The public hosted bot plays from a limited local music library, because YouTube blocks audio streaming from datacenter IPs. For the full game experience with any artist, self-host the bot — full instructions below.

Discord bot

🎮 Music guessing game

Start a game with any Spotify artist, listen to song previews in a voice channel and guess the title in chat. Points, hints after 15 seconds, leaderboard with badges and win streaks.

🎵 Spotify control

Link your own Spotify account and control playback right from Discord: play, pause, skip, volume and now-playing info — each user controls their own device.

Slack bot

The Slack version is a separate project designed around how Slack works — no voice channels, so the game lives entirely in chat. The bot posts a ~15-second audio clip in the channel, and whoever writes the title first wins the point. Same leaderboard, streaks and badges as the Discord version, tracked per workspace.

💬 Chat-based guessing game

/vinylbot-quiz_start uploads an audio clip as a file in the channel and starts a 30-second round, with a hint dropping after 15. First correct guess in chat wins — 10 rounds per game, then the final leaderboard.

🔓 No login required

Unlike the Discord bot, no one needs to link a personal Spotify account to play — artist and track search run entirely on VinylBot's own Spotify app credentials.
