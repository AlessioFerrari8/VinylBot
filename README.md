# VinylBot

A "guess the song" music quiz bot with Spotify-powered search: the bot posts a short audio clip, first to type the right title in chat wins the point. Per-workspace/server leaderboard, streaks, and badges.

This repo hosts three sibling projects — Discord bot, Slack bot, landing page — but for now only the **Slack bot** is documented and ready to use, see [`bot_slack/README.md`](bot_slack/README.md) for setup and commands. Discord (`bot_ds/`) and the website (`website/`) will get their own docs later.


For now just focus on the slack bot, ignore the other twos.
